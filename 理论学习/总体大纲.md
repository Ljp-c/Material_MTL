## 详细课层大纲

### 第零层：基础装备层
**时间**：≤1周（不会Python则+1周）

| 模块 | 内容 | 掌握标准 |
|------|------|----------|
| Python最小集 | 变量、列表、字典、for/if、函数、类、`import` | 能独立写50行脚本 |
| numpy | 数组创建、索引切片、`np.dot()` | 能做矩阵乘法 |
| matplotlib | `plt.scatter()`、`plt.show()` | 能画散点图 |
| 工程素养 | pip/conda装包、读Traceback、用AI查问题 | 遇到报错不慌 |

---

### 第一层：看见晶体
**项目-1：Hello Crystal** | **时间**：1-2周

| 维度 | 内容 |
|------|------|
| **核心目标** | 读取CIF → 打印坐标表 → 画3D图 → 移动原子观察变化 |
| **第一性原理** | 晶体 = 晶格(Lattice) + 原子类型(Species) + 分数坐标(Frac Coords) |
| **关键技能** | `pymatgen.Structure`、分数坐标↔笛卡尔坐标转换、周期性边界条件 |
| **最小数学** | 矩阵乘法、3D欧氏距离 |
| **交付物** | 一个Python脚本：输入CIF → 输出坐标表+3D图+最近邻距离统计 |
| **常见坑** | 分数坐标超出[0,1)需fold；不要一上来背230个空间群 |

**项目-1 进阶：空间群与Wyckoff位置** | **时间**：+1周（合计2周）

| 维度 | 内容 |
|------|------|
| **核心目标** | 理解空间群概念；提取Wyckoff位置；可视化标记 |
| **第一性原理** | 空间群 = 平移对称 + 点群对称；Wyckoff位置是对称性的直接产物 |
| **关键技能** | `get_space_group_info()`、`spglib`分析、Wyckoff字母与多重性 |
| **最小数学** | 群论直觉：对称操作 = 坐标变换后结构不变 |
| **交付物** | 脚本：输入CIF → 输出空间群编号+Wyckoff分析+颜色标记可视化 |

---

### 第二层：预测属性
**项目0：属性预言家** | **时间**：3-4周

| 维度 | 内容 |
|------|------|
| **核心目标** | 输入晶体结构 → 预测形成能（用Materials Project数据训练GNN） |
| **第一性原理** | 结构决定性质；图是最自然的晶体表示（原子=节点，键=边） |
| **关键技能** | Crystal Graph构建、PyTorch `DataLoader`、训练循环、MAE评估 |
| **最小数学** | 梯度下降直觉、均方误差MSE |
| **交付物** | CGCNN训练脚本，在MP氧化物子集上MAE < 0.3 eV/atom |
| **必读论文** | CGCNN (Xie & Grossman, 2018) §2-3 |
| **常见坑** | 从子集开始不要全量；形成能是广延量需除以原子数 |

**项目0 进阶：ALIGNN与迁移学习** | **时间**：嵌入第3-4周

| 维度 | 内容 |
|------|------|
| **核心目标** | 实现键角图更新；DFT预训练→实验数据微调 |
| **第一性原理** | 键角编码三体相互作用；迁移学习弥合DFT与实验偏差 |
| **关键技能** | 边-边图构建、`requires_grad=False`冻结层、替换预测头微调 |
| **最小数学** | 边门控直觉：用相邻键特征控制信息流动 |
| **交付物** | ALIGNN脚本 + 迁移学习对比报告 + MatBench benchmark结果 |
| **必读论文** | ALIGNN (Choudhary & DeCost, 2021) §2；ALIGNN-CSP §3 |
| **常见坑** | ALIGNN内存是CGCNN的3-5倍；冻结层数需网格搜索 |

---

### 第三层：生成晶体
**项目1：晶体梦工厂** | **时间**：3-4周

| 维度 | 内容 |
|------|------|
| **核心目标** | 训练模型随机生成合理晶体结构（无条件） |
| **第一性原理** | 晶体存在于高维流形上；表征是生成的前提 |
| **关键技能** | SLICES表征（132个token）、GPT自回归、因果掩码、采样参数 |
| **最小数学** | Softmax、交叉熵损失、Gumbel-Softmax直觉 |
| **交付物** | SLICES+GPT模型，1万条子集训练，解码成功率>50%，物理合理性>30% |
| **必读论文** | SLICES (Xiao et al., 2023)；MatterGPT架构；nanoGPT源码 |
| **常见坑** | SLICES解码失败率30-50%是正常的；先过拟合100条验证pipeline；Exposure Bias |

**项目1.5：变分晶体工坊** | **时间**：4-6周

| 维度   | 内容  |
|------  |------|
| **核心目标**   | 用VAE+Wyckoff表征生成晶体；实现潜在空间插值 |
| **第一性原理** | VAE = 编码器+解码器+KL正则；潜在空间连续光滑 |
| **关键技能**   | β-VAE架构、重参数化trick、Wyckoff编码/解码、潜在空间可视化 |
| **最小数学**   | 变分推断直觉（ELBO = 重建项 - KL项）；重参数化trick |
| **交付物**     | β-VAE（β=1,4,8对比）+ PCA降维可视化 + 插值动画 + 生成统计 |
| **必读论文**   | Kingma & Welling 2014 §2；CDVAE；WyCryst |
| **常见坑**     | 后验坍塌（Posterior Collapse）；Wyckoff解码需投影约束；VAE生成偏保守 |

---

### 第四层：条件控制
**项目2：分子建筑师** | **时间**：4-6周

| 维度 | 内容 |
|------|------|
| **核心目标** | 给定形成能，生成对应晶体；验证条件一致性 |
| **第一性原理** | 条件生成 = 学习P(结构\|属性)；CFG = 有条件方向与无条件方向的插值 |
| **关键技能** | 属性嵌入、CFG数学原理、CFG强度w调参、属性回测验证 |
| **最小数学** | 条件概率直觉；线性插值 |
| **交付物** | 条件生成模型 + 100个生成结构回测 + MAE<0.3 eV/atom |
| **必读论文** | Classifier-Free Guidance (Ho & Salimans, 2022) §3 |
| **常见坑** | 预测器精度是瓶颈；w越大属性越准但多样性越差；需画w-MAE-多样性权衡图 |

**项目2.5：遗传探索者** | **时间**：2-3周

| 维度 | 内容 |
|------|------|
| **核心目标** | 用遗传算法搜索最优掺杂方案 |
| **第一性原理** | 模拟自然选择：种群→适应度→选择→交叉→变异→精英保留 |
| **关键技能** | 二进制染色体编码、锦标赛选择、交叉/变异算子、适应度函数设计 |
| **最小数学** | 组合优化直觉；Hamming距离 |
| **交付物** | GA+DNN混合搜索脚本 + 收敛曲线 + 随机搜索对比报告 |
| **必读论文** | Atilgan & Hu 论文全文；遗传算法教材前2章 |
| **常见坑** | 无效结构爆炸；早熟收敛；适应度函数设计是核心；ML替代DFT评估 |

---

### 第五层：材料搜索
**项目3：材料猎人** | **时间**：6-10周

| 维度 | 内容 |
|------|------|
| **核心目标** | 在化学空间中搜索最优材料；生成→ML筛选→DFT验证 |
| **第一性原理** | 材料发现 = 搜索；生成模型提议+ML筛选+DFT确认各司其职 |
| **关键技能** | 扩散模型直觉、M3GNet/MACE快速弛豫、贝叶斯优化、Ehull计算 |
| **最小数学** | 高斯过程直觉；期望改进(EI)直觉 |
| **交付物** | 搜索pipeline + 1000候选→50筛选→5个DFT验证 + 最优结构报告 |
| **必读论文** | M3GNet/CGCNN力场；Materials Project Ehull文档 |
| **常见坑** | 扩散模型非必需；ML势能只筛差的不选好的；Ehull<0.1为亚稳态 |

**项目3 进阶：多目标帕累托优化** | **时间**：+2-3周（嵌入项目3）

| 维度 | 内容 |
|------|------|
| **核心目标** | 同时优化形成能+带隙；找到帕累托前沿 |
| **第一性原理** | 帕累托最优 = 不牺牲A就无法改善B；前沿 = 所有最优解集合 |
| **关键技能** | 加权和标量化、qEHVI采集函数、双输出CGCNN、前沿可视化 |
| **最小数学** | 目标归一化；参考点选择 |
| **交付物** | 多目标搜索脚本 + 帕累托前沿散点图 + 3个DFT验证对比 |
| **必读论文** | Babu等 §3.3-3.4；BoTorch Multi-Objective BO教程 |
| **常见坑** | 目标必须归一化；两目标可能强反相关；qEHVI复杂度指数增长 |

**【穿插模块】DFT基础速成** | **时间**：1-2周（分散在项目3-4期间）

| 维度 | 内容 |
|------|------|
| **核心目标** | 理解DFT输入输出；会操作VASP/MP API；能排查常见报错 |
| **第一性原理** | DFT = Kohn-Sham方程 → 电子密度 → 总能量；交换关联泛函是唯一直接近似 |
| **关键技能** | MP API查询、VASP四文件(INCAR/KPOINTS/POSCAR/POTCAR)、核心参数含义 |
| **交付物** | MP API拉取脚本 + 个人DFT计算记录 + VASP报错速查表 |
| **常见坑** | 不要从头学DFT理论；赝势需与MP一致；API需注册Key |

### 第六层：闭环发现
**项目4：闭环发现者** | **时间**：8-12周

| 维度 | 内容 |
|------|------|
| **核心目标** | AI自主提议→验证→迭代；最小化昂贵计算次数，最大化信息增益 |
| **第一性原理** | 计算机快但不准，DFT准但慢；闭环 = 最优分工 |
| **关键技能** | 主动学习策略（不确定性/多样性/EI）、增量训练、DFT工作流管理 |
| **最小数学** | 信息增益直觉；Pareto最优 |
| **交付物** | 自动化闭环脚本 + 预算控制（如100次DFT）+ 最优3个结构 |
| **必读论文** | Babu等 §5.7 主动学习 |
| **常见坑** | 强烈建议合作（你负责ML，合作者负责DFT）；DFT失败是常态；周期长需耐心 |

---

### 第七层：方法对比与论文复现
**项目5：方法论比武** | **时间**：4-6周

| 维度 | 内容 |
|------|------|
| **核心目标** | 系统对比方法；完整复现一篇论文；写技术报告 |
| **第一性原理** | 没有万能方法；理解每种方法的"能力边界"和"失效模式" |
| **关键技能** | 标准评估指标、StructureMatcher、统计显著性、bootstrap、学术写作 |
| **最小数学** | Bootstrap置信区间；效应量Cohen's d |
| **交付物** | 方法对比表 + 4页论文复现报告 + GitHub整理仓库 |
| **常见坑** | 公平对比很难；复现大概率得不到原文数字；诚实分析差异更有价值 |
