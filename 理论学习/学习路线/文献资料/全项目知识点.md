## 项目 1：晶体梦工厂（SLICES + GPT）
### "我能随机生成看起来合理的晶体"

---

### 1.1 物理第一性原理：晶体是一个"高维流形"

晶体结构不是任意原子排列的均匀分布。在巨大的构型空间中，**只有极小一部分排列是物理上合理的晶体**——原子不能太近（泡利排斥），也不能太远（失去成键），配位数要符合化学规律，电荷要平衡。

这些"合理结构"在数学上构成一个**低维流形**（Manifold），嵌入在高维的坐标空间中。

> **生成模型的任务**：学习这个流形的形状，然后从中采样。

### 1.2 为什么用"离散序列"表示晶体？

晶体是三维连续对象，但生成模型（尤其是 GPT）擅长处理**一维离散序列**（如文本）。所以我们需要一种**编码方案**：把三维晶体"压扁"成一串 token。

**SLICES（Simplified Linear Input Crystal Encoding System）**就是这样一种编码：

- **节点 token**：原子符号（Si, O, Fe...）+ 节点索引（0–19）
- **边 token**：27 种边标签（如 `+++`, `o+o`），描述原子间的连接关系
- **总词汇表**：132 个 token

**物理直觉**：SLICES 把晶体图（节点+边）序列化为一个"化学句子"。就像 SMILES 把分子图变成字符串一样。

### 1.3 自回归生成（Autoregressive Generation）

GPT 的核心机制极其简单：

> **给定前 N 个 token，预测第 N+1 个 token。**

在晶体生成中：
```
输入：<开始符> Si 0 +++ O 1 o+o ...
预测：下一个 token 是什么？
输出：Fe
输入：<开始符> Si 0 +++ O 1 o+o Fe ...
预测：下一个 token 是什么？
...
直到生成 <结束符>
```

**物理对应**：这不是在三维空间中"摆放"原子，而是在**化学语言的语法规则**中，一个字一个字地"写"出一个晶体结构。

### 1.4 Transformer Decoder 的核心组件

你不需要理解全部细节，只需要知道这三样东西在做什么：

| 组件 | 物理/算法直觉 |
|------|-------------|
| **因果掩码（Causal Mask）** | 模型只能"向左看"。预测第 5 个 token 时，不能偷看第 6、7、8 个 token。这保证了生成顺序的因果性。 |
| **多头自注意力** | 每个 token 都能"关注"序列中所有前面的 token，自动学习长距离依赖（比如序列开头的空间群信息会影响后面的原子选择）。 |
| **位置编码** | 告诉模型"这个 token 是在序列的第几个位置"。没有它，模型会把 `[Si, O]` 和 `[O, Si]` 当成一回事。 |

### 1.5 从概率到结构：采样策略

模型输出的不是确定的下一个 token，而是**132 个 token 的概率分布**。

**温度参数（Temperature, T）**：
- T → 0：总是选概率最高的 token（贪婪）。生成结构"安全"但极度重复，缺乏多样性。
- T = 1：按原始概率采样。平衡。
- T → ∞：完全随机采样。生成结构混乱，物理无效。

**Top-p 采样（Nucleus Sampling）**：
只从累积概率达到 p（如 0.9）的最小 token 集合中采样。既避免选到概率极低的怪 token，又保留一定随机性。

### 1.6 曝光偏差（Exposure Bias）：自回归模型的阿喀琉斯之踵

**训练时**：模型看到的是**真实的**前一个 token（Teacher Forcing）。
```
真实序列：A → B → C → D
训练：给定 A，预测 B（看到真值 A）
      给定 A,B，预测 C（看到真值 A,B）
```

**推理时**：模型看到的是**自己生成的**前一个 token。
```
生成：A → B'（可能错了）→ C''（基于错误的 B'）→ D'''（错误累积）
```

**物理后果**：训练 loss 很低，但生成质量可能很差。因为一旦某个 token 生成错误，后续所有 token 都建立在错误的基础上，**误差级联放大**。

**缓解方法**：Scheduled Sampling（训练时逐步用模型自己的预测替代真实 token）、Beam Search（保留多个候选序列）。

### 1.7 SLICES 解码：从字符串回到三维结构

生成 SLICES 字符串只是第一步。你必须把它**解码**回 `pymatgen.Structure`。

**解码流程**：
1. 解析 token 序列，重建原子连接图
2. 根据边标签推断键长和晶格参数
3. 求解三维坐标（图嵌入问题）
4. 验证物理合理性（原子不重叠、键长合理）

**关键事实**：SLICES 解码失败率高达 **30–50%**。生成的字符串可能根本对应不了任何有效的三维晶体。这不是你的 bug，是表征本身的局限。

## 项目 1.5：变分晶体工坊（VAE + Wyckoff）
### "换一种方式生成晶体"

---

### 2.1 物理动机：为什么需要第二种生成范式？

GPT（自回归）生成的是**离散序列**，一次只能"写"一个 token。它有两个问题：
1. **生成是单向的**：你很难在生成到一半时"回去修改"前面的原子
2. **潜在空间不连续**：两个相似的 SLICES 字符串可能解码出完全不同的结构，反之亦然

VAE（变分自编码器）提供了一种**连续的、可插值的**生成方式。

### 2.2 VAE 的物理图像：压缩与重建

想象晶体结构是一个高维物体（成千上万个坐标值）。VAE 把它**压缩**到一个低维的"潜在向量" z（比如 64 维），然后再从这个 z **重建**回原始结构。

**编码器（Encoder）**：
- 输入：晶体结构（Wyckoff 表征）
- 输出：不是单一的 z，而是**一个概率分布**——均值 μ 和对数方差 logσ²

**重参数化技巧（Reparameterization Trick）**：
$$z = \mu + \sigma \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

**物理直觉**：我们不把晶体映射到一个确定的点，而是映射到一个**高斯云**。这个云的中心是 μ，云的宽度是 σ。采样时从这个云里随机取一个点。

**为什么这样做？**
- 如果编码器直接输出 z，模型会学会"死记硬背"（过拟合）
- 输出分布 + 采样，强迫潜在空间**连续且光滑**——相近的 z 解码出相近的晶体

### 2.3 ELBO：VAE 的损失函数

VAE 优化的是**证据下界（Evidence Lower BOund）**：

$$\mathcal{L} = \underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{重建损失}} - \underbrace{D_{\text{KL}}(q(z|x) \| p(z))}_{\text{KL 散度}}$$

**重建损失**：解码出来的结构和输入结构有多像？（原子类型、坐标、晶格的差异）

**KL 散度**：编码出的分布 $q(z|x)$ 离标准正态分布 $\mathcal{N}(0,I)$ 有多远？

**物理意义**：
- 重建损失保证模型能"记住"训练数据
- KL 散度强迫潜在空间**规则化**——你不能把不同晶体编码到天涯海角，它们必须挤在一个标准正态球里。这保证了**从球里随机采样一个 z，解码出来也是一个合理的晶体**。

### 2.4 后验坍塌（Posterior Collapse）

VAE 最经典的训练失败模式。

**症状**：KL 散度趋于 0，重建损失不再下降。

**物理原因**：解码器"偷懒"了。它发现不管 z 是什么，都输出一个"平均晶体"（比如最常见的 NaCl 结构）。这样重建损失虽然不低，但也不需要费力去学习复杂的 z→结构映射。KL 散度变成 0 是因为编码器把 σ→0，所有晶体都编码到同一个点。

**解法**：
- **KL Annealing**：训练初期 KL 权重为 0，只优化重建；后期逐渐加大 KL 权重
- **β-VAE**：给 KL 项加一个系数 β。β > 1 时，更强调潜在空间的规则化，但可能牺牲重建质量

### 2.5 Wyckoff 表征在 VAE 中的优势

项目 1 用 SLICES（离散字符串），项目 1.5 用 Wyckoff（结构化参数）。

**Wyckoff 输入格式**：
- 空间群编号（如 225）
- 每个 Wyckoff 位置：原子类型 + 代表坐标 + 占据率

**为什么更适合 VAE**：
- Wyckoff 是**连续参数**（坐标是 0–1 之间的实数），天然适合 VAE 的连续潜在空间
- 对称性由空间群**硬编码**，不需要模型从数据中学习
- 插值有意义：在潜在空间两点之间线性插值 → 解码出的结构在化学上呈现"过渡态"

**插值的物理图像**：
```
晶体 A（NaCl） ← z_A
晶体 B（CsCl） ← z_B

插值点 z = 0.5*z_A + 0.5*z_B
解码 → 中间结构：配位数、键长介于 NaCl 和 CsCl 之间
```

## 项目 2：分子建筑师（条件生成 + CFG）
### "给定形成能，生成对应晶体"

---

### 3.1 物理问题：从无条件到有条件

项目 1 和 1.5 生成的是**随机**晶体。但材料设计的真实需求是：

> "我要一个带隙 2.5 eV 的稳定氧化物，用来当光电材料。"

你需要模型学习**条件概率**：
$$P(\text{结构} \mid \text{属性})$$

而不是无条件概率：
$$P(\text{结构})$$

### 3.2 属性嵌入（Property Embedding）

如何把"形成能 = -2.5 eV/atom"这个标量注入生成过程？

**方法**：把标量通过一个小的 MLP 映射成一个向量（如 64 维），然后**加到或拼到**每个 token 的嵌入向量上。

**物理直觉**：模型在生成每一个原子/token 时，都"记得"目标属性是什么。就像作曲时给定一个"悲伤"的情感标签，每个音符的生成都受这个标签影响。

### 3.3 无分类器引导（Classifier-Free Guidance, CFG）

这是条件生成的核心技术。

**直觉**：模型同时学习两个任务：
1. **无条件生成**：$P(\text{结构})$（不告诉它目标属性）
2. **条件生成**：$P(\text{结构} \mid \text{属性})$（告诉它目标属性）

训练时，以 10% 的概率把条件属性"屏蔽"掉（换成空向量），让模型学会无条件生成。

**推理时的 CFG 公式**：
$$\text{logits}_{\text{final}} = \text{logits}_{\text{uncond}} + w \cdot (\text{logits}_{\text{cond}} - \text{logits}_{\text{uncond}})$$

**物理意义**：
- $\text{logits}_{\text{cond}} - \text{logits}_{\text{uncond}}$ = "条件带来的方向修正"
- $w$ = 引导强度。$w=1$ 就是普通条件生成；$w>1$ 强化条件约束

**引导强度 w 的权衡**：

| w | 属性贴合度 | 结构多样性 | 物理有效性 |
|---|-----------|-----------|-----------|
| 1 | 中 | 高 | 高 |
| 3–5 | 高 | 中 | 中 |
| >10 | 极高 | 极低（模式坍塌） | 低（强行满足条件，结构畸形）|

**物理原因**：w 太大时，模型为了"讨好"条件属性，会生成一些统计上罕见、物理上可疑的结构，就像为了押韵而写出病句。

### 3.4 回测验证（Property Predictor Feedback）

生成 100 个"形成能 = -2.5 eV"的晶体后，你怎么知道它们真的满足条件？

**用项目 0 的 CGCNN/ALIGNN 回测**：
- 把生成的结构输入属性预测器
- 得到预测的形成能
- 计算 MAE

**关键约束**：回测 MAE 不可能优于预测器本身的精度。如果你的 CGCNN 在测试集上 MAE = 0.5 eV，那条件生成的回测 MAE 不可能低于 0.5 eV。**先升级预测器，再谈条件生成。**

## 项目 2.5：遗传探索者（GA + ML 适应度）
### "用进化搜索最优掺杂方案"

---

### 4.1 物理动机：当深度学习不适用时

不是所有问题都有 10 万条 DFT 数据。假设你只有 50 个实验测得的掺杂数据，深度学习方法会严重过拟合。

**遗传算法（Genetic Algorithm, GA）不需要训练数据**。它只需要一个能判断"这个方案好不好"的函数——适应度函数（Fitness Function）。

### 4.2 GA 的物理图像：模拟自然选择

```
第 0 代：随机生成 40 个掺杂方案（种群）
  ↓
评估：用 M3GNet/CGCNN 计算每个方案的形成能（适应度）
  ↓
选择：锦标赛选择——随机抽 3 个，取最好的做父代
  ↓
交叉：两个父代交换部分掺杂位点（产生新方案）
  ↓
变异：随机翻转某个位点（引入多样性）
  ↓
精英保留：最好的 4 个直接进入下一代（防止优秀基因丢失）
  ↓
第 1 代：重复...
```

### 4.3 染色体编码

掺杂问题中，染色体是一个**二进制向量**：

```
宿主：TiO₂ 的 2×2×2 超胞，有 32 个 Ti 位点
染色体：[0, 1, 0, 0, 1, 0, ...]  （长度 32）
         ↑     ↑
       不掺杂  掺杂（Nb替换Ti）
```

### 4.4 适应度函数设计

这是 GA 的**核心**，也是最难的部分。

**简单适应度**：只最小化形成能
$$F = -\Delta H_f$$

**问题**：GA 可能找到形成能极低但结构畸形的解（比如所有掺杂原子挤在一起，晶格畸变巨大）。

**改进适应度**：加入结构合理性惩罚
$$F = -\Delta H_f - \lambda \cdot \text{畸变度}$$

**物理直觉**：不仅要求能量低，还要求结构"看起来正常"（键长分布合理、没有异常短的距离）。

### 4.5 早熟收敛（Premature Convergence）

**症状**：种群在第 3 代就失去了多样性，所有个体几乎一模一样。

**物理原因**：选择压力太大 + 变异率太低。优秀的个体迅速统治种群，但可能只是**局部最优**。

**解法**：
- 增大变异概率
- 引入"小生境"（Niching）：惩罚过于相似的个体，强迫种群分散
- 增大种群规模

### 4.6 为什么 GA + ML 是绝配？

| | 单独 GA（DFT 适应度） | 单独 ML | GA + ML |
|--|---------------------|---------|---------|
| 速度 | 极慢（每次评估几小时） | 快（毫秒级） | 快 |
| 数据需求 | 不需要 | 需要大量数据 | 不需要 |
| 精度 | 高 | 依赖训练集 | 中（ML 近似，最后 DFT 验证）|

**工作流**：GA 提出候选 → ML 势能（M3GNet/CGCNN）快速打分 → 选最好的几个做 DFT 验证。

## 项目 3：材料猎人（扩散模型 + 贝叶斯优化 + 多目标）
### "在化学空间中搜索最优材料"

---

### 5.1 扩散模型的物理图像：从噪声中雕刻晶体

想象一块大理石（噪声），雕塑家（神经网络）一点一点凿掉多余部分，最后露出大卫像（晶体结构）。

**前向过程（加噪声）**：
$$x_0 \rightarrow x_1 \rightarrow x_2 \rightarrow \dots \rightarrow x_T$$

从完美晶体 $x_0$ 开始，每一步随机加一点高斯噪声。经过 $T$ 步（如 1000 步），结构变成纯粹的高斯噪声，完全看不出原样。

**反向过程（去噪声）**：
$$x_T \rightarrow x_{T-1} \rightarrow \dots \rightarrow x_0$$

神经网络学习"给定当前噪声状态 $x_t$，预测噪声是什么，然后减掉它"。一步一步，从纯噪声恢复出合理晶体。

**物理直觉**：前向过程是"破坏晶体"，反向过程是"学习如何从混乱中重建秩序"。模型学到的不是晶体本身，而是**"什么不是晶体"**——它知道哪些原子排布是噪声、哪些是有序的。

### 5.2 为什么扩散模型生成质量好？

相比 VAE（容易模糊）和 GAN（容易模式坍塌），扩散模型的优势：

1. **训练稳定**：没有对抗训练，目标函数是明确的 MSE（预测噪声）
2. **覆盖模式全**：因为是从纯噪声开始，理论上可以到达潜在空间的任何区域
3. **条件控制自然**：在每一步去噪声时注入条件信息（如目标形成能）

### 5.3 贝叶斯优化（Bayesian Optimization, BO）

扩散模型生成晶体，BO 负责**决定在哪里搜索**。

**问题**：化学空间巨大（比如 Li-Fe-O 三元系可能有数百万种候选结构），你不能每个都算 DFT。

**BO 的物理直觉**：

你已经在几个点上做了 DFT（得到了真实能量），BO 做三件事：
1. **拟合代理模型**：用一个高斯过程（Gaussian Process, GP）拟合已有点的能量，同时给出**预测不确定性**
2. **采集函数**：在"预测能量低"且"不确定性高"的地方采样下一个点
   - 期望改进（Expected Improvement, EI）："这个点比当前最优好的概率期望"
3. **更新**：在新点上做 DFT，加入数据集，重复

**为什么有效**：BO 平衡了**探索**（去不确定高的地方）和**利用**（去能量低的地方），用最少的 DFT 计算找到最优解。

### 5.4 多目标帕累托优化（Multi-Objective Pareto）

现实材料设计从来不是单目标。

**例子**：锂电池正极材料需要：
- 形成能低（热力学稳定）
- 带隙适中（电子导电性）
- 体积变化小（循环稳定性）

这些目标往往**互相冲突**：
- 形成能最低的相可能是金属（带隙 = 0）——不适合做绝缘电解质
- 带隙大的绝缘体可能结构松散（体积变化大）

**帕累托最优（Pareto Optimal）**：
一个解是帕累托最优的，如果**你无法在不恶化至少一个目标的前提下改善另一个目标**。

**帕累托前沿（Pareto Front）**：所有帕累托最优解组成的曲面。好的多目标优化算法应该**覆盖整个前沿**，而不是只聚集在某一段。

**qEHVI（期望超体积改进）**：BO 的多目标版本。它不只优化一个能量，而是同时优化多个目标，主动寻找前沿上的"空白区域"。

### 5.5 M3GNet / MACE：快速筛选的物理基础

在 BO 或扩散模型生成候选后，你不能直接上 DFT（太慢）。你需要一个**快速的近似能量计算器**。

**M3GNet** 和 **MACE** 是**机器学习势能（ML Potential）**：
- 输入：原子类型 + 坐标
- 输出：体系总能量 + 每个原子的受力

**训练数据**：大量 DFT 计算结果（结构 + 能量 + 力）
**速度**：比 DFT 快 **1000–1,000,000 倍**
**精度**：接近 DFT，但对训练分布外的结构可能失效

**在材料搜索中的角色**：
```
生成 1000 个候选 → M3GNet 快速弛豫 + 算能量 → 筛选到 50 个 → DFT 验证 5 个
```

### 5.6 Ehull（凸包距离）：热力学稳定性的金标准

**形成能负**只说明比参考态稳定，但不一定比**所有竞争相**稳定。

**Ehull** = 你的结构的形成能 与 **相同成分所有已知相的凸包（Convex Hull）** 之间的垂直距离。

| Ehull | 物理含义 |
|-------|---------|
| 0 | 热力学最稳定（在凸包上） |
| < 0.1 eV/atom | 亚稳态，可能合成出来 |
| > 0.2 eV/atom | 不稳定，会自发分解为其他相 |

**为什么重要**：生成模型可能输出一个形成能 = -3.0 eV/atom 的结构，看起来很美。但如果已知相里有一个形成能 = -3.5 eV/atom 的，你的结构 Ehull = 0.5，**实际上根本不会存在**。

## 项目 4：闭环发现者
### "AI 自主提议 → 验证 → 迭代"

---

### 6.1 闭环的物理本质：最小化昂贵实验

材料发现的瓶颈从来不是"想不出候选"，而是**验证太贵**：
- 一次 DFT 计算：几小时到几天
- 一次实验合成：几周到几个月

**闭环的核心问题**：给定预算（比如只能做 100 次 DFT），怎么让每次计算带来的信息增益最大？

### 6.2 主动学习（Active Learning）

**不确定性采样**：
模型对某个候选结构的预测方差很大 → "我不确定这个结构好不好" → **优先计算它**，因为算完后能最大程度消除不确定性。

**多样性采样**：
选和已计算结构**最不一样**的候选。避免在已知的局部最优附近反复计算。

**期望改进（Expected Improvement）**：
选"最可能超越当前最优解"的候选。平衡了"探索新区域"和"改进已知最优"。

### 6.3 反馈策略：增量训练 vs 全量重训

**增量训练（Incremental）**：
把新 DFT 数据加入训练集，只训几个 epoch。快，但可能遗忘旧知识。

**全量重训（Full Retraining）**：
每次都用全部数据从头训练。稳，但慢。

**物理权衡**：如果新数据和旧数据分布差异大（发现了全新化学空间），必须全量重训。如果只是微调，增量即可。

### 6.4 DFT 失败的自动化处理

DFT 计算经常失败：
- SCF 不收敛
- 结构弛豫跑飞（原子飞散）
- 电子步震荡

**custodian** 是一个自动错误处理库：
- 检测失败类型
- 自动调整参数（如增大 K 点密度、调整混合参数）
- 重新提交计算

**在闭环中的意义**：没有它，你的 pipeline 每跑几轮就会因为一次 DFT 失败而中断。

---

### 7.1 评估指标体系

| 指标 | 定义 | 物理意义 |
|------|------|---------|
| **有效性（Validity）** | 能通过物理检查的结构比例 | 原子不重叠、键长合理、电荷平衡 |
| **唯一性（Uniqueness）** | 去重后结构数 / 生成总数 | 模型有没有反复生成同一个结构 |
| **新颖性（Novelty）** | 不在训练集中的结构比例 | 模型是在"记忆"还是"创造" |
| **覆盖率（Coverage）** | 生成集覆盖测试集多样性的程度 | 模型有没有探索到足够多的模式 |
| **条件一致性** | 生成结构的回测属性与目标属性的 MAE | 条件控制是否有效 |

**指标间的冲突**：
- 高有效性 往往伴随 低新颖性（模型只生成"安全"的已知结构）
- 高新颖性 往往伴随 低有效性（模型探索未知区域，但很多结构不合理）
- 好的生成模型要在**帕累托前沿**上找到平衡

### 7.2 结构匹配（Structure Matching）

怎么判断两个晶体是"同一个"？

**pymatgen.StructureMatcher**：
1. 尝试所有可能的晶格映射
2. 比较原子坐标（考虑周期性、平移、置换）
3. 如果 RMS 距离 < 阈值（如 0.2 Å），认为是同一结构

### 7.3 论文复现的方法论

**为什么复现很难**：
- 随机种子不同
- 数据划分不同
- 超参数细节缺失（学习率调度、权重衰减、早停条件）
- 后处理过滤不同

**正确的复现态度**：
> 不要追求"数字完全一致"，要追求"趋势一致 + 误差范围可解释"。在报告中诚实分析差异原因，比强行凑数字更有价值。

## DFT 基础速成模块

### 8.1 Kohn-Sham 方程的物理直觉（再回顾）

**核心洞察**：用 **N 个独立的虚构电子** 替代 **N 个相互作用的电子**。

每个虚构电子在一个**有效势**中运动：
$$V_{\text{eff}}(\mathbf{r}) = V_{\text{ext}}(\mathbf{r}) + V_{\text{Hartree}}(\mathbf{r}) + V_{\text{XC}}(\mathbf{r})$$

- $V_{\text{ext}}$：原子核的吸引（精确已知）
- $V_{\text{Hartree}}$：电子间的经典库仑排斥（精确已知）
- $V_{\text{XC}}$：交换关联势（**唯一近似**）

**DFT 的误差全部来自 $V_{\text{XC}}$ 的选择**（PBE、LDA、HSE06 等）。

### 8.2 VASP 的四大输入文件

| 文件 | 作用 |
|------|------|
| **POSCAR** | 晶体结构（晶格 + 原子类型 + 坐标） |
| **POTCAR** | 赝势（描述原子核和内层电子对价电子的有效势） |
| **KPOINTS** | 布里渊区采样网格密度（越密越准越慢） |
| **INCAR** | 计算参数（截断能、收敛标准、计算类型） |

**最关键的 4 个参数**：
- **ENCUT**：平面波截断能（通常设为 POTCAR 推荐值的 1.3–1.5 倍）
- **KPOINTS**：k 点密度（长晶格方向用较少 k 点）
- **ISIF**：弛豫类型（2 = 只弛豫原子位置，3 = 弛豫原子 + 晶格）
- **EDIFF**：电子自洽收敛标准（能量变化 < EDIFF 认为收敛）

### 8.3 常见 DFT 失败与排查

| 症状 | 物理原因 | 解法 |
|------|---------|------|
| SCF 不收敛 | 初始猜测差、K 点太少、混合参数不当 | 先用 ML 势能弛豫得到好初猜；增加 K 点；调整 AMIX/BMIX |
| 结构弛豫跑飞 | 初始结构不合理、力太大 | 分步弛豫（先 ISIF=2，再 ISIF=3）；降低步长 |
| 能带带隙为 0 | PBE 泛函固有缺陷（低估带隙） | 换 HSE06（贵 10–100 倍）或 GW 方法 |
| 磁性体系能量异常 | 自旋极化设置错误 | 设置 ISPIN=2，给定合理的 MAGMOM 初猜 |

## 一、物理第一性原理：晶体是什么？

### 1.1 晶体的最小完备描述

晶体在物理上只需要三个要素即可唯一确定：

> **晶体 = 晶格（Lattice）+ 原子类型（Species）+ 分数坐标（Fractional Coordinates）**

其他一切概念——空间群、Wyckoff 位置、对称性、倒易空间——都是这三者的**衍生结构**。

#### 晶格（Lattice）：晶体的"骨架"

晶格是由三个基向量 **a, b, c** 张成的平行六面体。在数学上，它是一个 **3×3 矩阵**：

$$
\mathbf{L} = \begin{bmatrix} a_x & a_y & a_z \\ b_x & b_y & b_z \\ c_x & c_y & c_z \end{bmatrix}
$$

晶格定义了晶体的**周期性**：整个晶体可以看作这个平行六面体在三维空间中无限平移堆砌而成。

#### 原子类型（Species）：谁坐在那里？

就是化学元素：Si, O, Fe, Li... 每种元素的核电荷数决定了它吸引/排斥电子的能力，从而决定了化学键的本质。

#### 分数坐标（Fractional Coordinates）：位置的"百分比"

> **分数坐标** = 原子位置相对于晶格基向量的比例

如果一个原子的分数坐标是 $(0.5, 0.5, 0.5)$，它的真实空间位置是：
$$\mathbf{r}_{\text{cart}} = 0.5\mathbf{a} + 0.5\mathbf{b} + 0.5\mathbf{c}$$

矩阵形式：
$$\mathbf{r}_{\text{cart}} = \mathbf{r}_{\text{frac}} \cdot \mathbf{L}$$

**为什么晶体学偏爱分数坐标？**

1. **周期性自然体现**：分数坐标永远在 $[0, 1)$ 区间内。超出 1 就 fold 回来（周期性边界条件）。
2. **晶格形变不变性**：如果晶格被压缩或拉伸，分数坐标不变，只有晶格矩阵改变。这在模拟压力/温度效应时极其方便。
3. **对称性操作简化**：旋转、镜面反射在分数坐标下是线性变换。

### 1.2 周期性边界条件（Periodic Boundary Conditions, PBC）

晶体是无限大的，但我们只模拟一个晶胞。为了让晶胞"感觉"自己处于无限晶体中，我们规定：

> 如果一个原子从晶胞右边出去，它从左边进来；从上面出去，从下面进来。

数学上：
$$x_{\text{eff}} = x \mod 1.0$$

**物理意义**：消除了表面的影响。一个晶胞中的原子不仅和晶胞内的原子相互作用，还和相邻晶胞的镜像原子相互作用。

### 1.3 最近邻距离与最小镜像约定

计算两个原子的距离时，不能只算晶胞内的坐标差。因为原子可能"跨过边界"更近：

```
晶胞 A：原子在 0.1
晶胞 B（镜像）：原子在 0.9
直接差：|0.1 - 0.9| = 0.8
实际最小镜像距离：min(0.8, 1.0 - 0.8) = 0.2
```

**最小镜像约定（Minimum Image Convention）**：计算距离时，考虑所有周期性镜像，取最短的那个。

## 二、CIF 文件格式：晶体的"身份证"

CIF（Crystallographic Information File）是晶体结构的标准文本格式。它包含：

- **晶格参数**：a, b, c, α, β, γ
- **空间群**（可选，但强烈建议标注）
- **原子坐标表**：元素 + 分数坐标 (x, y, z) + 占据率（occupancy）

**占据率**：如果某个 Wyckoff 位置只有 80% 的概率被原子占据（比如掺杂或空位），占据率 = 0.8。

## 四、空间群（Space Group）

### 4.1 定义

**空间群** = 三维欧氏空间中，保持晶体结构不变的所有等距变换（对称操作）构成的群。

**构成元素**：
- **平移**：沿晶格矢量的整数倍平移
- **点操作**：旋转、镜面反射、反演
- **螺旋轴/滑移面**：平移 + 旋转/镜面的复合操作

**Fedorov 定理**：三维晶体中，这样的群只有 **230 种**。

### 4.2 编号 vs 符号

| | 编号 | 符号 |
|--|------|------|
| **形式** | 1–230 的整数 | 字符串（如 Fm-3m, P63/mmc） |
| **唯一性** | ✅ 唯一 | ⚠️ 同一空间群可能有等价写法 |
| **用途** | 程序计算、数据库索引 | 人类阅读 |

符号的含义（以 Fm-3m 为例）：
- **F**：面心晶格（Face-centered）
- **m**：镜面（mirror）
- **-3**：三重反演轴
- **m**：另一个镜面

## 五、Wyckoff 位置

### 5.1 定义

给定空间群 **G**，取空间中任意一点 **r**，将 G 中所有操作作用于 **r**，得到的点的集合称为 **r** 的**轨道**（orbit）。**一个 Wyckoff 位置就是一条轨道。**

**位置对称群** $G_{\mathbf{r}}$：保持 **r** 不动的对称操作构成的子群。

**多重性（Multiplicity）**：
$$m = \frac{|G|}{|G_{\mathbf{r}}|}$$

即轨道中独立等价点的数量。

### 5.2 Wyckoff 字母

在同一个空间群内部，Wyckoff 位置按位置对称性从高到低排序，标记为 **a, b, c, d...**

| 字母 | 对称性 | 多重性 | 坐标特征 |
|------|--------|--------|----------|
| **a** | 最高 | 最小 | 通常有固定坐标（如 0,0,0） |
| **b** | 高 | 较小 | 固定坐标 |
| ... | ... | ... | ... |
| **一般位置** | 无特殊对称 | 最大（= |G|） | 含自由参数 x, y, z |

**关键规则**：
- 字母越靠前，对称性越高，多重性越小。
- Wyckoff 字母**只在同一个空间群内**有意义。225 的 4a 和 227 的 4a 是完全不同的位置。

### 5.3 为什么 Wyckoff 对生成模型重要？

**直接坐标表示的问题**：
- 需要预测所有原子的坐标（如 20 个原子 → 60 个数）
- 模型必须自己学会对称性约束

**Wyckoff 表示的优势**：
- 只需预测"哪个 Wyckoff 位置坐什么元素"
- 对称性由晶体学规则**硬编码**，无需学习
- 搜索空间大幅缩减（如 8 个原子的晶胞可能只需 2 个独立坐标）

## 一、物理第一性原理：形成能是什么？

### 1.1 定义

形成能（Formation Energy）是从**标准参考态**构建晶体时的能量变化：

$$\Delta H_f = E_{\text{晶体}} - \sum_i n_i \mu_i$$

- $E_{\text{晶体}}$：晶体的总能量（通常由 DFT 计算）
- $n_i$：元素 $i$ 的原子数
- $\mu_i$：元素 $i$ 在标准参考态下的化学势（如纯金属块、O₂ 分子）

### 1.2 物理意义

| $\Delta H_f$ | 含义 |
|-------------|------|
| **< 0** | 放热反应，热力学有利，可能稳定存在 |
| **> 0** | 吸热反应，热力学不利，可能自发分解 |
| **越负** | 越稳定 |

**形成能是材料筛选的第一道门槛**。一个结构即使带隙、硬度再好，如果 $\Delta H_f > 0$，它连"存在"的资格都没有。

### 1.3 为什么用 "per atom"？

形成能是**广延量**（Extensive）：原子数越多，总能量越大。为了公平比较不同大小的晶体，必须除以原子数，变成**强度量**（Intensive）：

$$\Delta H_f^{\text{per atom}} = \frac{\Delta H_f}{N_{\text{atoms}}}$$

---

## 二、DFT 的物理直觉

### 2.1 多体问题的维度灾难

$N$ 个电子的波函数 $\Psi(\mathbf{r}_1, \mathbf{r}_2, ..., \mathbf{r}_N)$ 生活在 $3N$ 维空间中。对于 100 个电子，这是 300 维——不可计算。

### 2.2 Hohenberg-Kohn 定理

**核心洞察**：基态电子密度 $\rho(\mathbf{r})$（3 维函数）唯一确定了体系的全部基态性质。

> 我们不需要解 300 维的波函数，只需要找到一个 3 维的密度函数。

### 2.3 Kohn-Sham 方法

将真实的多体相互作用电子体系，映射为一个**虚构的非相互作用电子体系**。每个电子在一个**有效势** $V_{\text{eff}}(\mathbf{r})$ 中独立运动。

$$V_{\text{eff}}(\mathbf{r}) = V_{\text{ext}}(\mathbf{r}) + V_{\text{Hartree}}(\mathbf{r}) + V_{\text{XC}}(\mathbf{r})$$

**DFT 的唯一近似**：交换关联势 $V_{\text{XC}}$ 的选择（PBE、LDA、HSE06 等）。其余部分在 Kohn-Sham 框架下是严格精确的。

### 2.4 DFT 的速度瓶颈

- 一次计算：数小时到数天
- 精度：~meV/atom（相对于其他原子尺度方法）
- **矛盾**：精度高但太慢，无法用于高通量筛选

---

## 三、从物理到 ML：为什么结构能决定能量？

### 3.1 结构 → 电子云 → 能量

1. **原子类型**决定核电荷（吸引电子的能力）
2. **原子坐标**决定原子间距（太近 → 泡利排斥；太远 → 成键弱）
3. **晶格参数**决定整体密度
4. 以上共同决定**电子密度 $\rho(\mathbf{r})$ 的分布**
5. 电子密度决定**Kohn-Sham 总能量**

### 3.2 局部环境决定局部能量

每个原子的能量主要由其**局部环境**决定：
- Si 在四面体配位中 → 能量低（sp³ 杂化最优）
- Si 在八面体配位中 → 能量高（键角不匹配）
- O 在两个 Si 之间（桥氧）vs 三个 Si 之间 → 能量不同

**这个"局部性"是图神经网络能够工作的物理基础。**

## 四、图神经网络（GNN）的物理图像

### 4.1 晶体 = 图

| 图的元素 | 物理实体 |
|---------|---------|
| **节点** | 原子 |
| **边** | 近邻原子对（化学键/强相互作用） |
| **节点特征** | 原子类型（原子序数、电负性等） |
| **边特征** | 原子间距离 |

### 4.2 为什么不用 MLP 或 CNN？

**MLP 的问题**：
- 输入维度必须固定（不同晶体原子数不同）
- **排列敏感**：交换原子顺序，晶体物理不变，但输入向量变了
- **无局部性概念**：不知道谁是邻居

**CNN 的问题**：
- 假设规则网格（像素矩阵）
- 晶体原子排列**不规则**，邻居数不固定
- 强行栅格化会丢失原子精度

**GNN 的优势**：
- 处理任意大小和形状的图
- **排列不变**：聚合操作（sum/mean）与节点顺序无关
- **平移/旋转不变**：边特征用相对距离（标量），不是绝对坐标
- **局部性**：只连接近邻，尊重相互作用的短程性

### 4.3 消息传递 = 多体相互作用的层次近似

| 消息传递轮数 | 物理对应 |
|-------------|---------|
| **第 1 轮** | 两体相互作用（A 感知直接邻居 B） |
| **第 2 轮** | 三体相互作用（A 感知 B，B 感知 C → A 间接感知 C 和键角 ABC） |
| **第 3 轮+** | 更高阶多体关联，感受野不断扩大 |

## 五、CGCNN：晶体图卷积网络

### 5.1 核心操作

**节点嵌入**：把原子序数映射为向量（化学本性编码）

**边嵌入**：把连续距离映射为向量（相互作用强度编码）

**消息传递**：
```
对每个节点：
  收集所有邻居的消息 = f(邻居特征, 边特征)
  聚合 = mean/sum(所有邻居消息)
  更新自身 = g(旧状态, 聚合消息)
```

**读出（Readout）**：所有节点特征求平均 → 晶体全局表征 → 预测形成能

### 5.2 近邻截断（Cutoff Radius）

晶体是无限的，必须设定截断半径 $r_{\text{cut}}$（通常 5–8 Å），只连接距离 $< r_{\text{cut}}$ 的原子对。

**物理依据**：相互作用随距离指数衰减（库仑 $1/r$，范德华 $1/r^6$），远程贡献可忽略。

## 六、训练与评估：MSE vs MAE

### 6.1 为什么训练用 MSE？

**数学原因**：
- MSE 处处光滑可导，梯度大小与误差成正比
- 误差大时梯度大（快速修正），误差小时梯度小（精细微调）
- 对应高斯噪声假设下的最大似然估计

**MAE 的训练问题**：
- 梯度恒为 ±1，不随误差大小变化
- 在误差为 0 处不可导（尖点），导致震荡
- 大误差时修正动力不足，收敛慢

### 6.2 为什么评估用 MAE？

| 维度 | MSE | MAE |
|------|-----|-----|
| **单位** | (eV/atom)² | eV/atom |
| **物理可读性** | ❌ 需开根号 | ✅ 直接就是平均偏差 |
| **对异常值** | 平方放大，易被绑架 | 线性，更鲁棒 |
| **决策可用性** | 不能直接用于误差传播 | 可直接加减到预测值上 |

**MAE 的物理意义**：模型预测的形成能，平均来看比 DFT 真值偏差了多少 eV/atom。

**精度刻度**：
- ~0.1–0.2 eV/atom：接近 DFT 本身误差极限，很好
- ~0.3–0.5 eV/atom：可用，能区分稳定/不稳定
- >1.0 eV/atom：不可用

## 七、ALIGNN：加入键角的三体相互作用

### 7.1 CGCNN 的盲区

CGCNN 只用**原子间距**（边特征），对应**两体相互作用**。

**反例：金红石 vs 锐钛矿（都是 TiO₂）**
- Ti-O 键长几乎相同
- 配位数相同（Ti: 6, O: 3）
- 但 **O-Ti-O 键角分布完全不同** → 形成能不同

**CGCNN 无法区分**，因为它看不到键角。

### 7.2 键角的物理本质

键角是**三体相互作用的几何载体**：

```
    A
    |
    B
   / \
  C   D
```

角 ABC 描述了 A 和 C 相对于 B 的空间关系，决定了：
- A 和 C 的电子云是否在 B 附近重叠
- B 的杂化轨道取向
- 局部应力状态

### 7.3 ALIGNN 的边图（Line Graph）

**原图**：节点 = 原子，边 = 原子对
**边图（Line Graph）**：节点 = 原图的边（即化学键），边 = 两条原边共享一个原子（即存在一个键角）

**双层消息传递**：
1. **边图更新**：每条键"感知"周围其他键的角度关系（三体信息）
2. **原图更新**：每个原子"感知"邻居时，边特征已包含键角信息

### 7.4 迁移学习：DFT → 实验

**问题**：实验数据少（过拟合风险），DFT 数据多但有系统误差。

**物理直觉**：
- DFT 和实验共享**相同的物理规律**（原子怎么相互作用）
- 差异只在**数值刻度**（DFT 的交换关联近似导致系统偏移）

**策略**：
1. **预训练**：在大量 DFT 数据上训练 ALIGNN，学习"结构 → 能量"的映射
2. **冻结底层**：底层的消息传递层学到了通用物理规律，冻结参数
3. **微调顶层**：用少量实验数据重新训练预测头，校准绝对值

**为什么合理**：底层 GNN 学到的是"原子间相互作用"（物理真理，DFT 和实验都遵守），顶层学到的是"这个具体数据集的数值偏移"（可以调整）。
